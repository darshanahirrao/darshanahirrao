## Open-source tools

Eight tools for people who run agents in production. Each one is live, each one runs the analysis in your browser, and each one states its limits on the page rather than in a footnote.

- [permfuzz](https://permfuzz.vercel.app): what an agent can actually touch, read from its tool grants.
- [trifecta](https://trifecta-hazel.vercel.app): every path from outsider text to your data, and the single fix that breaks the most of them.
- [mcp-audit](https://mcp-audit-three.vercel.app): audit an MCP server before you connect it.
- [judge-audit](https://judge-audit.vercel.app): whether your LLM judge measures quality or noise.
- [compaction-cliff](https://compaction-cliff.vercel.app): what an agent forgets when its context is compacted.
- [agent-replay](https://agent-replay-plum.vercel.app): step through a failing run and find the frame that broke it.
- [model-forensics](https://model-forensics.vercel.app): the style signals in a model's output, measured and compared.
- [claim-check](https://claim-check-hazel.vercel.app): claims about AI, checked against the primary source that decides them.

The source for all eight is public, and the readme in each repository says what it finds, how it works and what it cannot do.
